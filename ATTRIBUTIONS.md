# Attributions

Security Orchestrator is built around established open-source projects. We
thank their maintainers and contributors:

- [Gitleaks](https://github.com/gitleaks/gitleaks) — secret detection.
- [TruffleHog](https://github.com/trufflesecurity/trufflehog) — credential and
  secret discovery.
- [Semgrep](https://github.com/semgrep/semgrep) — static analysis.
- [Trivy](https://github.com/aquasecurity/trivy) — vulnerability, secret, and
  configuration scanning.
- [OSV-Scanner](https://github.com/google/osv-scanner) — open-source
  dependency vulnerability scanning.
- [Checkov](https://github.com/bridgecrewio/checkov) — infrastructure-as-code
  policy scanning.
- [OWASP ZAP](https://github.com/zaproxy/zaproxy) — authorized web application
  testing.
- [Nuclei](https://github.com/projectdiscovery/nuclei) — template-driven
  authorized detection.
- [Strix](https://github.com/usestrix/strix) — optional agentic security
  testing integration.

The project does not claim authorship of these tools and does not include their
source code, binaries, templates, rules, or databases. See
`THIRD_PARTY_NOTICES.md` for license and integration-boundary details.
